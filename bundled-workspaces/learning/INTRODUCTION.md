# 学习教练 · 每天多学一点

这是你的本地学习工作区。目录结构由 MyAgents 创建，学习资料以这里的普通文件为事实源。

- **每天一张卡**：3–5 分钟的学习卡片落在 `cards/`，主题和节奏由你在 `03-USER.md` 中设置。
- **学习有记忆**：学了什么、掌握到哪、下一步学什么，记录在 `.claude/rules/04-LEARNING-STATE.md`（AI 每次重写，只留当前仍成立的内容）和 `topics/` 里，教练每次出卡前都会先看它们。
- **知识有连接**：每张卡片的 `related` 字段链着相关知识点，复习时顺着链走。
- **你的资料你做主**：导入的 Markdown 先进 `inbox/`；教练实际阅读并整理后，才归入 `sources/` 并在卡片里引用。
- **测验与复盘**：`assessments/` 存测验结果，`reviews/weekly|monthly/` 存周月复盘；重复犯的错才升级进 `mistakes/`。
- **进度与版本记录**：教练按 `05-LEARNING-MEMORY.md` 区分出卡、练习与确认学完，记录有证据的完成时间，保留重新学习历史。操作收尾后可提交本次相关学习文件；关联远程仓库并明确授权后才同步。定时记忆更新仍需在工作区设置中启用。

## 从这里开始

1. 在「任务中心 → 学习」里点**设置每日 9:00 推送**，每天早上收到一张新卡；想要周复盘就点**设置每周日复盘**。
2. 打开任意卡片，点**开始讨论**，教练会带着你把知识点学透。
3. 学完标记，不感兴趣就点跳过——教练会记住并调整方向。

目录说明：`archive/` 存年度归档；所有文件都是普通 Markdown，随时可以用任何编辑器打开。
